# Changelog

Все значимые изменения этого проекта будут документироваться в этом файле.

Формат основан на Keep a Changelog.

---

## [Unreleased]

### Added

- API создания и отмены заказов с атомарным списанием и возвратом остатка в Supabase.
- Автоматическая отмена заказов `PENDING` через 15 минут и возврат зарезервированных товаров.
- Тесты отображения и фильтрации товаров, валидации заказа и скрипты для ручной проверки покупки и отмены.

### Changed

- Главная страница показывает опубликованные товары с остатком больше нуля; каталог сохраняет товары без остатка.
- Обновлены метаданные сайта и README, маршрутизация переведена на `proxy.ts` для Next.js 16.
- Удалены неиспользуемые шаблонные ресурсы, UI-заготовка и связанные зависимости.

### Fixed

- Неопубликованный товар больше не доступен по прямой ссылке.
- Карточка и страница товара показывают отсутствие товара на складе.
- Конкурирующие заказы не могут списать больше товара, чем есть в наличии.
