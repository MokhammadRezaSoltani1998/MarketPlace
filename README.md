# MarketPlace

Маркетплейс на Next.js 16, React 19 и Supabase. Есть регистрация и вход, каталог с поиском и сортировкой, страницы товаров, корзина, оформление и просмотр заказов. Продавец может управлять своими товарами, администратор — товарами и категориями. Серверные API создают и отменяют заказы.

## Запуск

1. Установите зависимости: `npm ci`.
2. Создайте `.env.local` с `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` своего проекта Supabase.
3. Примените SQL-файлы из `supabase/migrations` к своей БД в порядке имён.
4. Запустите `npm run dev` и откройте http://localhost:3000.

Для управления каталогом назначьте владельцу магазина роль `ADMIN` в таблице `profiles`; роль `SELLER` позволяет управлять собственными товарами. Новая миграция добавляет политики доступа для каталога, корзины и заказов, а также публичный Storage bucket `product-images`. Исходная схема таблиц пока не хранится в репозитории: перед применением миграций она должна существовать в Supabase.

Покупатель может добавлять товары в корзину, оформлять заказ и видеть его статус. Заказ резервирует остаток на 15 минут: подтверждённая вовремя оплата переводит его в `PAID`, иначе заказ отменяется с возвратом остатка.

Для тестовой оплаты задайте на сервере `SUPABASE_SERVICE_ROLE_KEY` и `MOCK_PAYMENT_WEBHOOK_SECRET`. Секреты не должны иметь префикс `NEXT_PUBLIC_`. По умолчанию используется `MockPaymentProvider`: кнопка оплаты открывает тестовую страницу подтверждения. Сервер принимает подписанные уведомления по `/api/payments/webhook/mock`; платёжные ключи и реальные списания в этой реализации не используются. Для другого провайдера нужно реализовать контракт `PaymentProvider` и зарегистрировать его в `getPaymentProvider`, сохранив общую обработку заказа.

## Проверки

- `npx tsc --noEmit` — TypeScript.
- `npm run lint` — ESLint.
- `npm test -- --runInBand` — тесты Jest.
- `npm run build` — сборка Next.js.

## Структура

- `src/app` — маршруты и страницы Next.js.
- `src/entities` — товары и другие доменные сущности.
- `src/features` — авторизация, каталог, корзина и оформление заказа.
- `src/widgets` — составные блоки интерфейса.
- `src/shared` — клиенты Supabase, типы и общая инфраструктура.
- `scripts` — ручные проверки заказов; для них нужен `.env.test` с `ORDER_TEST_COOKIE`.
